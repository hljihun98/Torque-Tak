# Torque Tak!

볼트 규격, 강도 등급, 마찰계수, 체결 조건을 바탕으로 권장 체결 토크를 빠르게 확인하는 모바일 우선 정적 웹 애플리케이션입니다.

## 주요 기능

- 볼트 호칭경과 강도 등급 선택
- 나사부·좌면 마찰계수 설정
- 목표 축력과 권장 체결 토크 계산
- 외력 조건을 반영한 체결 검토
- 계산 결과 및 참고 정보를 한 화면에서 확인
- 별도 설치 없이 브라우저에서 실행

> 계산 결과는 설계 검토를 돕기 위한 참고값입니다. 실제 체결 조건, 표면처리, 윤활 상태, 공차, 사용 장비 및 적용 규격을 함께 검토하세요.

## 프로젝트 구조

```text
Torque-Tak/
├─ index.html              # 앱 진입점과 화면 마크업
├─ assets/
│  ├─ css/
│  │  └─ styles.css        # 레이아웃, 컴포넌트, 반응형 스타일
│  └─ js/
│     └─ app.js            # 계산식, 상태 관리, 화면 동작
└─ README.md
```

## 실행 방법

빌드 과정이나 패키지 설치가 필요하지 않습니다.

### 파일로 바로 실행

`index.html`을 브라우저에서 열면 됩니다.

### 로컬 서버로 실행

프로젝트 루트에서 다음 중 하나를 실행한 뒤 표시된 주소로 접속하세요.

```bash
python -m http.server 8000
```

또는:

```bash
npx serve .
```

기본 접속 주소는 `http://localhost:8000`입니다.

## 배포

모든 리소스가 상대 경로를 사용하므로 GitHub Pages, Netlify, Vercel 등 정적 호스팅 서비스에 별도 빌드 없이 배포할 수 있습니다.

GitHub Pages를 사용하는 경우 저장소의 **Settings → Pages**에서 배포 소스를 `main` 브랜치의 `/(root)`로 선택하세요.
